Каталог — Справка

Рабочий центр каталога: дерево категорий слева, редактор категории справа (настройки, атрибуты, товары). Здесь управляется вся структура магазина.

Как пользоваться

  • Выбрать категорию: кликните по узлу дерева слева — справа откроются вкладки редактора.
  • Создать категорию: кнопка «+ Категория» добавляет корневой узел; «+ Подкатегория» — дочерний к выбранному.
  • Настройки категории: вкладка «Настройки» — название, slug, описание, активность.
  • Атрибуты: вкладка «Атрибуты» — типизированные поля товаров (Размер, Цвет, Материал…). Каждый атрибут наследуется подкатегориями.
  • Товары: вкладка «Товары» — таблица с фильтрацией, сортировкой, добавлением нового товара.
  • Теги: кнопка «Теги» открывает управление метками, применяемыми к товарам.
  • Поиск категории: поле «Найти категорию...» фильтрует дерево по названию.

Горячие клавиши

  • Esc — закрыть открытое модальное окно (форма категории, форма атрибута, лайтбокс).
  • Enter — применить фильтр в поле таблицы товаров.
  • Shift + клик по чекбоксу — выделить диапазон строк в таблице.

Подсказки

  • Товары привязываются только к листовым (конечным) категориям — без дочерних узлов.
  • Атрибут, созданный на родительской категории, наследуется всеми потомками и не редактируется на них.
  • Снятая галка «Активна» скрывает категорию и все её товары на витрине без удаления из базы.
  • Код атрибута (snake_case) нельзя изменить после сохранения — по нему работают фильтры витрины.

Новая категория
?

Категория — узел в дереве каталога.

  • Название — отображается в каталоге и админке.
  • Slug — латиница в URL. Если оставить пустым, генерируется из названия.
  • Родитель — позиция в дереве. «Без родителя» = корневой раздел.
  • Описание — текст под заголовком категории на витрине.
  • Активна — снятая галка скрывает категорию и все её товары на витрине, в БД ничего не удаляется.

Удалить можно через таб «Настройки» у выбранной категории, и только если у неё нет дочерних узлов и товаров.

Атрибут
?

Атрибут — поле, которое описывает товар в этой категории. Например, Размер, Материал, Цвет.

  • Код — латиница, snake_case, неизменяем после создания (по нему фильтры на витрине).
  • Тип определяет, как выглядит ввод значения у товара: Текст, Число, Да/нет, Один вариант/Несколько вариантов (тогда внизу появятся «Варианты»), Дата, Ссылка, Файл, Изображение.
  • Единица — для числовых (см, кг, EUR).
  • Обязательный — без значения товар нельзя сохранить.
  • Варианты (для select/multiselect) — порядок отображения = порядок в списке.

Атрибут, заданный на категории, наследуется всеми её потомками. На потомке его не редактируют — только смотрят.
