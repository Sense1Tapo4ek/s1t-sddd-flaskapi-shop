Telegram-бот магазина

Один токен бота на магазин. Используется для уведомлений о заказах, кодов входа и восстановления пароля. Chat ID для получения сообщений каждый администратор привязывает к своему аккаунту на странице «Аккаунт».

Получить токен — у @BotFather. Нажмите «?» рядом с заголовком для пошаговой инструкции.
