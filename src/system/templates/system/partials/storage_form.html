Режим хранения

Локально — файлы кладутся в каталог приложения (media/products) и отдаются Flask'ом. S3 — заливаются в внешний бакет и отдаются по public URL. Переключение применяется сразу. Старые файлы при смене режима не мигрируют автоматически.

S3 параметры

Бакет должен быть публично читаемым (s3:GetObject для всех). Презайн в MVP не используется. Public URL прописывается в Product.images как есть.

Пустое поле — оставить текущий секрет. Сам секрет наружу не отдаётся.

Префикс, к которому добавляется ключ объекта (products/<uuid>.<ext>).

Перед сохранением

Снимите галочку если вы переключаетесь обратно на локальный режим. При активном S3 и неудачной проверке настройки не сохраняются.
