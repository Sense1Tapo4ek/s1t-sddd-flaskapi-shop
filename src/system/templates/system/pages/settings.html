Зачем нужен бот.

  • Мгновенные уведомления о новых заказах.
  • Одноразовые коды для смены пароля и восстановления доступа.

Архитектура: один токен бота на весь магазин (хранится в этой вкладке) и персональный Chat ID у каждого администратора (привязывается на странице «Аккаунт»).

Шаг 1. Создать бота.

  1. Откройте Telegram и найдите @BotFather.
  2. Отправьте команду /newbot.
  3. Введите отображаемое имя бота (например, «Мой магазин — уведомления»).
  4. Введите username бота — должен заканчиваться на bot (например, myshop_notify_bot).
  5. BotFather пришлёт строку токена вида 1234567890:ABCdef... — это секрет, не публикуйте.

Шаг 2. Сохранить токен здесь.

  1. Вставьте токен в поле «Токен бота» на этой вкладке.
  2. Нажмите «Сохранить».

Шаг 3. Привязать Chat ID к своему аккаунту.

  1. Откройте диалог со своим ботом (по ссылке от BotFather) и нажмите «Запустить» / отправьте /start.
  2. Перейдите на страницу «Аккаунт».
  3. Нажмите «Получить Chat ID» — система автоматически найдёт ваш диалог.
  4. Сохраните привязку.

Важно:

  • Между /start и кнопкой «Получить Chat ID» должно пройти не более 15 минут — Telegram сам очищает очередь обновлений.
  • Каждый администратор делает шаг 3 для своего аккаунта — Chat ID индивидуальный.
  • Если перевыпустили токен у BotFather — пересохраните его здесь; старый перестаёт работать сразу.
{% else %}
  • Приложение: Имя приложения и подпись админ-панели — без правки кода и без перезапуска.
