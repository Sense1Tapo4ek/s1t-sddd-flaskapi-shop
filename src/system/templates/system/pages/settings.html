Telegram-бот отправляет уведомления о заказах и одноразовые коды входа / смены пароля. Один токен на весь магазин; Chat ID — индивидуально для каждого администратора.

Как подключить — три шага

Шаг 1. Создать бота.

  1. Найдите в Telegram @BotFather и отправьте /newbot.
  2. Введите имя и username (заканчивается на bot).
  3. BotFather пришлёт токен вида 1234567890:ABCdef... — не публикуйте.

Шаг 2. Сохранить токен.

  1. Вставьте токен в поле «Токен бота» и нажмите «Сохранить».

Шаг 3. Привязать Chat ID.

  1. Откройте бота в Telegram, отправьте /start.
  2. Перейдите на страницу «Аккаунт» и нажмите «Получить Chat ID».
  3. Сохраните привязку.

Подсказки

  • Между /start и «Получить Chat ID» — не более 15 минут.
  • Каждый администратор привязывает Chat ID самостоятельно на странице «Аккаунт».
  • Перевыпустили токен у BotFather — пересохраните его здесь; старый перестаёт работать мгновенно.
{% else %}

Общие настройки магазина: имя, контакты, карта и соцсети. Изменения применяются мгновенно без перезапуска.

Как пользоваться

  • Приложение: имя магазина и подпись панели управления — отображаются в заголовке страниц.
  • Контакты: телефон, email, адрес и режим работы — используются в шапке, подвале и на странице контактов.
  • Карта: широта и долгота для интерактивной карты; оставьте пустыми, если карту показывать не нужно.
  • Соцсети: полная ссылка на Instagram (начиная с https://); пустое поле — иконка скрыта.
  • Сохранить: кнопка «Сохранить» внизу формы — изменения вступают в силу немедленно.

Горячие клавиши

  • Esc — закрыть это окно справки.

Подсказки

  • Вкладки «Магазин», «Telegram», «Хранилище» переключаются через боковое меню слева.
  • Права владельца на каталог задаются переменными ACCESS_OWNER_CAN_* в .env и применяются на старте процесса — через UI не меняются.
